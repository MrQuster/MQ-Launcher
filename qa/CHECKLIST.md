# MQ Launcher — Visual & UI QA Checklist

Чек-лист для комплексной проверки интерфейса (матрица разрешений, масштабов, тем, состояний данных, клавиатурной навигации и доступности).

## 1. Геометрия, вёрстка и адаптивность
- [ ] Отсутствуют наложения интерактивных элементов (`overlaps == 0` в `checks.py`).
- [ ] Отсутствует обрезка текста и контролов (`clipped == 0`, без обрезанных кнопок/полей ввода).
- [ ] Нет горизонтального скролла или выхода контента за пределы viewport при `960×600`, `1180×740`, `1920×1080`.
- [ ] Сайдбар корректно переключается между полным и компактным режимом, не перекрывая основной контент.
- [ ] Модальные окна и диалоги центрированы, помещаются в `960×600` (включая масштаб `1.5×`/`2.0×`) и имеют внутренний скролл при нехватке высоты.
- [ ] В сетке (grid) и списке (list) карточки/строки выровнены по единой сетке, отступы консистентны.

## 2. Интерактивность, размеры целей и тултипы
- [ ] Все кликабельные элементы (кнопки, иконки, переключатели, поля ввода, вкладки) имеют размер hit-target `>= 24×24 px`.
- [ ] Все кнопки с одной иконкой (`icon_button`) и элементы без видимого текста имеют понятный `tooltip`.
- [ ] Все интерактивные элементы имеют уникальные `id` (нет `duplicate_ids`).
- [ ] Нет «мёртвых» кнопок: каждый клик вызывает изменение UI, открытие диалога/меню, смену состояния или уведомление (если не помечен `allow_noop`).
- [ ] Состояния `hover`, `active`, `focus`, `disabled` визуально различимы.

## 3. Контрастность и темы (6 пресетов)
Проверка во всех 6 темах: `MatteDark`, `PrismClassicDark`, `ModrinthEmerald`, `CatppuccinMocha`, `Nord`, `LightClean`:
- [ ] Основной текст на фоне панелей/карточек соответствует WCAG AA (`>= 4.5:1`).
- [ ] Вторичный/подсказочный текст (`text_muted`), бейджи и иконки читаемы (`>= 3.0:1` минимум, `>= 4.5:1` для мелкого текста).
- [ ] Текст на акцентных кнопках (`accent_fg` на `accent`) имеет достаточный контраст.
- [ ] В светлой теме (`LightClean`) нет «белого на белом» или слишком тёмных/грязных границ; в тёмных темах видны разделители, рамки инпутов и выделение активной вкладки.

## 4. Типографика, масштаб и локализация
Проверка при масштабах `1.0×`, `1.5×`, `2.0×`:
- [ ] Нет наезжания строк, разрывов слов посреди буквы или выхода бейджей за края карточек.
- [ ] В русской локали нет непереведённых английских UI-строк (кроме допустимых технических терминов/брендов из `EN_ALLOWLIST`).
- [ ] Отсутствуют заглушки (`TODO`, `FIXME`, `Lorem`, `Coming soon`, жаргон) и неуместные эмодзи.
- [ ] Переключение языка (`ru` ↔ `en`) обновляет все видимые подписи без артефактов.

## 5. Экраны и состояния данных
- [ ] **Инстансы (пусто):** пустое состояние с понятным призывом к действию («Создать сборку», «Импорт сборки»).
- [ ] **Инстансы (1 / 6 / 30 сборок):** корректная работа сетки и списка, поиск, фильтрация, скролл при 30 элементах, выбор карточки, панель деталей.
- [ ] **Создание инстанса / Импорт:** открытие модалки, выбор версии MC и загрузчика (Vanilla/Fabric/Forge/NeoForge/Quilt), валидация имени, закрытие без создания.
- [ ] **Детали инстанса:** все вкладки (Обзор, Моды/Ресурсы, Настройки инстанса, Логи/Консоль, Миры/Скриншоты при наличии).
- [ ] **Каталог:** поиск, фильтры, переключение источников (Modrinth / CurseForge), карточки проектов, диалог установки.
- [ ] **Загрузки:** пустое состояние / активные или завершённые задачи, кнопки управления.
- [ ] **Производительность:** метрики, графики/индикаторы, отсутствие пустых белых пятен.
- [ ] **Аккаунты:** вкладки (Microsoft / Ely.by / Офлайн), добавление офлайн-аккаунта, список аккаунтов, переключение/удаление.
- [ ] **Настройки:** все секции (`Оформление`, `Запуск`, `Язык и локализация`, `Сеть и API`, `Каталог`, `Обновления`, `О программе`), сохранение/изменение параметров.
- [ ] **Уведомления (Toast) и контекстные меню:** появление, читаемость, закрытие, отсутствие перекрытия важных кнопок навсегда.

## 6. Клавиатурная навигация и стабильность
- [ ] `Tab` / `Shift+Tab` перемещают фокус по интерактивным элементам.
- [ ] `Esc` закрывает открытые модальные окна, выпадающие списки и контекстные меню.
- [ ] Хоткеи (`Ctrl+N` для создания инстанса и др.) работают корректно и не конфликтуют с вводом текста.
- [ ] Нет паник, `ERROR` в логах и зависаний; `frame_stats` p99 в пределах нормы (`< 16 ms` в покое/навигации).
